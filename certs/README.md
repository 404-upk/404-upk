Корневой сертификат Минцифры (`russian_trusted_root_ca.cer`), которым подписан сервер GigaChat API.
Без него Python не доверяет серверу Сбера и не подключается к GigaChat.

Это публичный сертификат, секрета в нём нет, поэтому он лежит в репозитории.
Официальный источник: https://www.gosuslugi.ru/crt
