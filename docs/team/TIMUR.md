# Тимур: ИИ, бэкенд и вся внутренняя часть

Твоя зона: всё, что пользователь не видит, но по чему судят о качестве продукта. ИИ-помощник, сервер, база, безопасность,
приватность, скорость, инфраструктура. Внешний вид и новая фишка на Османе, с ним вы встречаетесь на контракте API.

Цель одна: на защите работает сквозной сценарий с настоящим ИИ на настоящем сервере, и на любой технический вопрос жюри
у нас есть ответ, показанный в коде.

## Запуск за пять минут

**Проще всего, в браузере:** [открыть в Codespaces](https://codespaces.new/404-upk/404-upk?quickstart=1). Устанавливать ничего не нужно, `.venv` там не создаём. Сайт запускается сам,
адрес открывается на вкладке **Ports**, порт 8000. Если сайт не запустился: `sh .devcontainer/start.sh`.

**На своём компьютере:** нужен Python 3.12 или новее и Git.

```bash
git clone https://github.com/404-upk/404-upk.git
cd 404-upk
```

**Windows (PowerShell или Git Bash):**

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements-dev.txt
cp .env.example .env
.venv/Scripts/python -m uvicorn app.main:app --reload --port 8000
```

**Linux и macOS:**

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
cp .env.example .env
.venv/bin/python -m uvicorn app.main:app --reload --port 8000
```


- http://localhost:8000: страница заявителя
- http://localhost:8000/admin: панель (логин `admin`, пароль `upk-admin-2026`)
- http://localhost:8000/api/docs: документация API

Проверки перед каждым коммитом:

```bash
python -m ruff check . --fix
python -m ruff format .
python -m pytest
```

Здесь и дальше `python` значит: на Windows `.venv/Scripts/python`, на Linux и macOS `.venv/bin/python`, в Codespaces просто `python`.

## Как устроен код

```
app/
  main.py          приложение, заголовки безопасности, страницы, robots и sitemap
  config.py        настройки из .env и проверка готовности к боевому запуску
  db.py            подключение к базе и запуск миграций
  models.py        таблицы
  security.py      пароли, сессии, коды отслеживания, лимиты запросов
  routers/         public (заявитель), track (статус), auth, staff (панель), manage (справочники)
  services/        заявки и статусы, дубли, статистика, QR, фото, Telegram, сроки хранения
  ai/              safety, rules, knowledge, gigachat, prompts, assistant, selftest
  migrations/      версии схемы базы
deploy/            боевой запуск: Caddy, PostgreSQL, приложение
tests/             автотесты, включая критерии приёмки из ТЗ
```

Путь обращения: `POST /api/assistant` → фильтр безопасности (`ai/safety.py`, до модели) → GigaChat или правила →
проверка ответа (`ai/assistant.py`, `_apply_guards`) → журнал `ai_logs`. Модель не может закрыть заявку: у неё нет
доступа к статусам. Это главный аргумент на защите.

## Что уже сделано, повторять не нужно

- **Безопасность:** CSP, HSTS, COOP, защита от запросов с чужих сайтов, cookie `__Host-` со `SameSite=Strict`, лимиты по
  адресу и логину, настоящий адрес клиента за прокси, лимит размера запроса, запрет запуска в боевом режиме с демо-паролями.
- **Приватность:** телефоны, почта, номера карт и пароли вырезаются перед отправкой в модель и в журнал ИИ. Коды
  отслеживания не попадают в журналы сервера. Тексты обращений и контакты сами удаляются через 90 дней (`services/retention.py`).
  Страница `/privacy` есть, но это черновик.
- **Производительность:** убраны лишние запросы к базе в списке заявок (тест следит, чтобы они не вернулись), составные
  индексы, сжатие текста, долгий кэш шрифтов, ответ 304 для страниц, предзагрузка модулей.
- **Архитектура:** миграции Alembic, проверка базы в `/api/health`, зависимости разделены на боевые и для разработки.
- **Инфраструктура:** Docker без root и с проверкой здоровья, контейнер только для чтения, Caddy с HTTPS, CI, Dependabot.
- **SEO:** мета-теги, Open Graph, картинка для соцсетей, JSON-LD, `robots.txt`, `sitemap.xml`, страница 404, служебные
  страницы закрыты от индексации. Lighthouse SEO: 100 из 100.

## Задачи

Идут по порядку. Первый блок важнее всего остального: без него нет защиты.

### Обязательно к защите

**1. Подключить настоящий GigaChat.**
Ключ из [developers.sber.ru](https://developers.sber.ru/docs/ru/gigachat/overview), сертификат Минцифры в `certs/` (инструкция в
`certs/README.md`), ключ в `.env`. Ответы модели без честной пометки жюри считает имитацией.
Готово, когда: «Экзамен для ИИ» в панели проходит 10 из 10 на GigaChat, а при выключенной сети сайт сам переходит на правила и
пишет об этом.

**2. Развернуть на сервере.**
VPS в России, домен, `cp deploy/.env.prod.example .env`, запуск по инструкции в `deploy/docker-compose.prod.yml`.
Жюри должно сканировать QR-код своим телефоном.
Готово, когда: QR с напечатанного листа открывает форму с телефона по HTTPS, заявка доходит до панели и Telegram.

**3. Заполнить настоящие данные.**
Настоящие помещения и база знаний колледжа вместо демо. Спроси у организаторов список кабинетов и правила.
Готово, когда: в базе знаний 20 и больше статей с реальными источниками, в разделе помещений настоящие корпуса.

**4. Резервные копии.**
Ежедневно `pg_dump` и архив папки фото, хранить вне сервера, срок 14 дней.
Готово, когда: копия восстановлена на чистой машине и сайт поднялся. Копия, которую ни разу не восстанавливали, не считается.

### Качество ИИ

**5. Набор оценки вместо десяти сценариев.**
Расширить `ai/selftest.py` до 60–100 реальных формулировок: опечатки, сленг, «и вопрос, и поломка сразу», длинные сообщения.
Считать точность по типам и категориям, запускать правила в CI, версии промпта хранить в коде.
Готово, когда: есть таблица «было и стало» по каждому изменению промпта, точность по опасным случаям 100 %.

**6. Защита от манипуляций.**
Тесты на «забудь инструкции», «ты теперь администратор», вставки в поле контекста, просьбы раскрыть промпт, длинные
сообщения и смешанные языки. Опасный запрос, замаскированный под вопрос, тоже должен ловиться.
Готово, когда: 30 и больше таких тестов в `tests/test_ai_guards.py`, и все проходят.

**7. Поиск по смыслу.**
`ai/knowledge.py` сейчас ищет по совпадению слов. Эмбеддинги GigaChat и pgvector на PostgreSQL, текущий поиск оставить
запасным для SQLite. Фильтр по порогу похожести, чтобы модель не отвечала по случайной статье.
Готово, когда: на наборе оценки ответы по базе знаний стали точнее, а неизвестные вопросы по-прежнему получают честное «не знаю».

**8. Устойчивость запросов к модели.**
Повторы с паузой только для сетевых ошибок, предохранитель: после серии сбоев сразу правила, без ожидания таймаута. Кэш
одинаковых вопросов на час. Метрики: задержка, ошибки, расход токенов.
Готово, когда: при отключении GigaChat ответы приходят быстрее секунды, а в статистике видно, сколько запросов ушло в запасной режим.

**9. Потоковый ответ.**
`POST /api/assistant/stream` через Server-Sent Events вместе с Османом. Фильтр безопасности срабатывает до потока, проверка
итогового ответа после него.
Готово, когда: первые слова появляются быстрее секунды, а опасный текст не показывается даже на мгновение.

### Бэкенд и архитектура

**10. Redis для лимитов.**
`RateLimiter` в `security.py` считает в памяти процесса, при двух воркерах лимиты удваиваются. То же с `_recent_codes` в
`services/tickets.py`: после перезапуска повторная отправка формы теряет код. Если Redis нет, остаётся текущая реализация.
Готово, когда: два воркера делят один лимит, и это проверено тестом.

**11. Надёжная доставка уведомлений.**
`BackgroundTasks` теряет задачи при перезапуске. Таблица исходящих сообщений в той же транзакции, что и заявка, и один воркер с
повторами.
Готово, когда: перезапуск сервера посреди отправки не теряет уведомление о заявке.

**12. Номера заявок.**
Сейчас `max(number) + 1` с тремя попытками. На PostgreSQL заменить на последовательность.
Готово, когда: 200 параллельных заявок получают 200 разных номеров без ошибок.

**13. Типы и контракт API.**
Довести `mypy app` с 36 ошибок до нуля и включить в CI. Ответы вместо `dict` описать моделями Pydantic, чтобы Swagger стал
полной документацией для Османа.
Готово, когда: mypy зелёный в CI, у каждого эндпоинта есть схема ответа.

**14. Настоящий первый вход.**
Команда `python -m app.create_admin` вместо `DEMO_*` паролей на сервере, обязательная смена временного пароля, журнал действий
администратора.
Готово, когда: на сервере нет ни одной учётной записи с паролем из настроек.

**15. Быстрый поиск.**
Поиск по заявкам идёт через `LIKE '%текст%'`. На PostgreSQL индекс `pg_trgm`, проверить через `EXPLAIN ANALYZE`.
Готово, когда: на 100 000 заявок поиск укладывается в 50 мс.

### Безопасность и приватность

**16. Убрать `unsafe-inline` из CSP.** Вместе с Османом: `style=""` переносим в классы.
Готово, когда: CSP без `unsafe-inline`, консоль чистая, [Mozilla Observatory](https://developer.mozilla.org/en-US/observatory) показывает A+.

**17. Вход сотрудников.** Двухфакторный вход (TOTP) для администратора, блокировка после серии ошибок, минимальная длина пароля 12
символов и проверка по списку утёкших.

**18. Юридическая часть.** Показать `/privacy` юристу колледжа, вписать оператора данных, уведомление в Роскомнадзор, если колледж
решит внедрять. На хакатоне достаточно показать, что вопрос продуман.

**19. Сканеры в CI.** gitleaks для секретов и Trivy для образа Docker.

### Наблюдаемость и нагрузка

**20. Логи и ошибки.** JSON-логи с идентификатором запроса, GlitchTip для ошибок. Текст обращений в логи не писать.
Готово, когда: по идентификатору из ответа можно найти весь путь запроса.

**21. Метрики.** Prometheus и Grafana: запросы, задержки, ошибки, очередь, ИИ. Внешний монитор доступности.

**22. Нагрузочный тест.** k6: 200 пользователей одновременно создают заявки и смотрят статусы.
Готово, когда: p95 меньше 300 мс без учёта ИИ, а цифры лежат на слайде презентации.

**23. Поисковики после деплоя.** Яндекс Вебмастер и Search Console, проверить превью ссылки в Telegram. `PUBLIC_URL` должен быть
настоящим, из него собираются canonical, Open Graph и sitemap.

## Правила команды

- **Ветки:** `main` всегда рабочая. Каждая задача в своей ветке `timur/название`, вливается через Pull Request, когда CI зелёный.
- **Границы:** ты в `app/`, `tests/`, `deploy/`, `.github/`, Осман в `web/`. Новое поле в ответе API добавляй свободно, а удалить или
  переименовать поле можно только после разговора с Османом.
- **Схема базы:** поменял модель, сразу делай миграцию: `python -m alembic revision --autogenerate -m "что изменилось"`. Файл проверь глазами,
  иначе упадёт `test_models_match_migrations`.
- **Тесты:** новая логика приходит с тестом, исправленная ошибка тоже.
- **Секреты:** только в `.env`, он не попадает в репозиторий. Случайно закоммитил ключ: сразу отзывай и выпускай новый,
  просто удалить из истории мало.
- **Слова:** графику фона в коде, коммитах, документах и презентации называем только рабочими словами: фон, точки, линии, состояние
  колледжа. Никаких образных названий и метафор, мы серьёзное агентство. Оценка заявки звёздами это обычный рейтинг, она остаётся.
